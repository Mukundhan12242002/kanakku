Kanakku / Privacy

Privacy

Short version: nothing you type leaves your device.

  • All calculations run in your browser. There is no server and no database behind these pages.
  • Numbers you enter are not stored, not saved in cookies and not sent anywhere.
  • The pages load fonts from Google Fonts, which means Google sees a normal font request from your browser.
  • The site is hosted on GitHub Pages, which keeps ordinary server logs under GitHub's own privacy policy.
  • There is no analytics script and no advertising on the site at present. If that changes, this page will say exactly what is added before it goes live.
